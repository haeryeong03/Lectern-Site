Lectern Company — 거울 던전 (2단계-2: 키워드 · 코인 효과 + 관리자 셰르)  v2.9

[ 실행 ]
  압축을 풀고 index.html 을 크롬/엣지로 열면 됩니다. (서버 없이도 동작)
  세이브는 브라우저에 저장됩니다. (4단계에서 Firebase로 옮김)
  ※ 이전 버전에서 전투 중이던 세이브는 그 전투가 처음부터 다시 시작됩니다. (엔진이 바뀜)

[ 전투 방법 ]
  0. 매 턴 가장 먼저, 아래 맨 왼쪽 '셰르' 칸에서 관리자 카드 1장을 씁니다.
     카드를 누르고 → 버프를 줄 아군(스탠딩 또는 카드 칸)을 누르면 됩니다. 효과는 이번 턴에만.
  1. 수감자 칸에서 스킬 카드를 고릅니다. (공격 2장 + 수비 1장, 한 턴에 1장 / 숫자키 1~5)
  2. 적 머리 위 '주사위'를 누르면 합, 적 몸이나 명판을 누르면 일방 공격입니다.
     - 나를 노린 공격은 언제든, 동료를 노린 공격은 내 속도가 더 빠를 때만 가로챕니다.
     - ⛨ 주사위는 적의 수비입니다.
  2-1. E.G.O.: 수감자 칸 머리의 [E.G.O.] 버튼 → 장착한 E.G.O. 카드가 나옵니다.
     모아 둔 죄악 재화 + SP를 내고 스킬 대신 씁니다 (손패는 그대로). 연결 방법은 스킬과 같아요.
     버튼이 금색으로 빛나면 지금 쓸 수 있는 E.G.O.가 있다는 뜻. 모자라면 카드에 '재화 부족 / SP 부족 / 조건 미충족'이
     찍히고, 눌러 보면 무엇이 얼마나 모자란지 알려 줍니다. 쓰면 E.G.O. 카드가 날아드는 궁극기 연출이 나옵니다.
  3. 마우스를 올리면 무대 가운데 위 '정보창'에 합 승률 · 코인 효과 · 내성이 나옵니다.
  4. '전투 개시'(Enter)를 누르면 위쪽 ORDER 순서대로 진행됩니다. '자동 배치'로 빈 칸을 채울 수 있어요.

[ 화면 읽는 법 ]
  - 명판 아래 칩 = 키워드 (출혈 · 화상 · 파열 · 진동 · 침잠 · 호흡 · 충전 · 마비 · 방어막)
    ▸가 붙은 칩 = 다음 턴에 적용 / 꽉 찬 칩 = 이번 턴 적용 중 / 주황 테두리 = 셰르가 준 버프
  - SP 옆 작은 표시 = SP 구간 효과 (신속 1 · 앞면 고정 1 · 위력 +3 / 속박 1 · 뒷면 고정 1 · 패닉)
  - 카드의 코인: 파란색 = 앞면 고정 · 회색 = 뒷면 고정 · × = 마비로 사라짐
  - 화살표: 빨강 = 적의 공격 · 금색 = 합 · 파랑 = 내 일방 공격
  - 합에서 진 쪽은 코인이 깨지고 '적중 효과 없음' 표시 → [적중시] 계열 효과는 이긴 쪽만 발동
  - 죄악 재화: 스킬을 쓰면 그 스킬의 죄악 1개 → 턴이 끝날 때 지급, 던전이 끝날 때까지 계속 쌓임
    (위쪽 HUD의 [ SIN ] 칸 · 전투 화면 오른쪽 위 칸, '+숫자' = 이번 턴 끝에 들어올 몫)
  - SP: 합에서 이기면 +5 · 지면 −5 (수비 카드로 받아낸 겨룸도 같음) → 캐릭터 위에 'SP +5 / −5' 표시
  - 효과음: 오른쪽 위 ♪ 버튼으로 켜고 끔 (코인 · 합 · 피격 · 코인 파괴 · 셰르 불꽃)
